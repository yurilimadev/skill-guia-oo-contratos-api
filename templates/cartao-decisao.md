# Cartão de Decisão — <título curto>

Ordem fixa: a parte da pessoa vem antes de qualquer comentário da skill. Sem “Minha razão”, a skill não comenta a decisão; pergunta “por que você escolheria isso?”.

```text
Data e hora: AAAA-MM-DD HH:MM
Entrada/passo: Construir / Herdar / Operar · ...
Modo em que foi decidida: learn / job

## Sua parte
Decisão: ...
Minha razão: ...
Assunto: técnico / teórico / ambos (ambos = um cartão para cada)
Alternativa descartada e por quê: ...
O que me faria mudar de ideia: ...

## Crítica da skill (construtiva)
Ponto frágil do argumento: ...
Alternativa mais forte: ...
Pergunta que ainda falta responder: ...

## Decisão final (sempre da pessoa)
Mantenho / mudo: ...
Razão final, se diferente da minha razão: ...
Opções consideradas: A · B (· C)
Ganho: ...
Custo: ...
Reversível? porta de uma via / duas vias
Quando revisitar: ...
Evidência ou suposição ligada: ...
Registro permanente: docs/decisoes/NNNN-titulo.md (se aplicável)
```

Ao preencher, use uma frase simples por campo. Marque a escolha como provisória quando depender de uma suposição aberta; não esconda uma decisão de negócio dentro de uma solução técnica.
